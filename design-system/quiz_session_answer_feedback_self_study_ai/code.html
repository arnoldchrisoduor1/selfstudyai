lightbulb Conceptual Explanation

By requiring a strict majority quorum ((n/2) + 1), any two valid quorums in a cluster of size n must overlap by at least one node according to the pigeonhole principle. That shared node can only cast a single vote per term, mathematically precluding two candidates from winning simultaneous elections in disjoint partitions.
