# DataTable

Generic column/row table.

## Look

- Default: rounded-xl frame, border, card, shadow, sticky header, footer count.
- `embedded`: no outer frame. Sits flush in a parent card. Header uses muted wash. Footer is a hairline only.

## Behavior

- Header cells `scope="col"`.
- Row hover `bg-muted/80`. Short stagger unless reduced motion.
- Horizontal scroll inside the frame.
- Color is never the only meaning in a cell.
