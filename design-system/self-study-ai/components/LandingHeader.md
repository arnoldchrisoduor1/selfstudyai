# LandingHeader

Marketing site top bar.

## Anatomy

- Wordmark link to `/`
- Anchor links (Features, How it works, Pricing, FAQ)
- Primary CTA: Open app (placeholder URL when unset)

## Tokens

- Background: `bg-background`, bottom `border-border`
- Links: `text-muted-foreground` → `text-foreground` on hover
- CTA: `Button` primary
