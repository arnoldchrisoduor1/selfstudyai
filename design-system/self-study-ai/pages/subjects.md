# Subjects

List of study subjects. One column inside the app shell.

- Heading: Lexend, foreground on background.
- Primary action uses Primary and On Primary tokens.
- Empty list uses the card surface and muted text. No invented encouragement.
- Delete uses a dialog. Row Edit and Delete are quiet buttons, same height, sitting in the actions cell. Not gradient CTAs.
- Table text stays at least 16px. Row actions are at least 44px tall.
- Edit subject page: per-subject learning override panel below name/description (inherits vs override fields).
