# Settings

Profile, generic key/value settings, AI providers, question defaults, and learning.

## Layout

- Tabs: Profile | Settings | Account & sync | AI providers | Questions | Learning
- AI providers: list, add/edit form with SecretInput, test connection, set default
- Re-embed warning when embedding model changes
- Questions: burst size, cognitive-level mix, default grounding mode, web search provider CRUD + test
- Learning: retention, daily goal, new cap, mix ratio, points summary, test defaults, timezone via SettingRow
